# Інформатика онлайн — шкільний кабінет

Вчитель публікує уроки (теорію й завдання складає Claude), учні здають відповіді, вчитель оцінює й коментує.

Один сервіс FastAPI віддає сторінку (`static/index.html`) та API (`app/main.py`). Дані — Postgres, файли — S3-сумісне сховище.

## Деплой на Render

1. New → Blueprint → вибрати цей репозиторій (Render прочитає `render.yaml`).
2. Вписати змінні:
   - `DATABASE_URL` — рядок підключення до Postgres;
   - `ANTHROPIC_API_KEY` — ключ Claude API (генерація уроків, модель `claude-haiku-5-5`);
   - `S3_ENDPOINT` (напр. `https://fra1.digitaloceanspaces.com`), `S3_REGION` (напр. `fra1`), `S3_BUCKET`, `S3_KEY`, `S3_SECRET` — приватний бакет для файлів учнів.
3. `SECRET_KEY` і `SETUP_CODE` Render згенерує сам. Значення `SETUP_CODE` подивитися в Environment — воно потрібне один раз.
4. Відкрити сайт → «Перший запуск» → зареєструвати першого вчителя з кодом `SETUP_CODE`.

Схема бази (`schema.sql`) застосовується сама під час старту. Без `ANTHROPIC_API_KEY` не працює генерація, без `S3_*` — завантаження файлів; решта працює.

## Як користуватися

- **Учні:** розділ «Учні» → вписати клас і список → роздрукувати логіни й PIN-коди. PIN показується один раз; загублений замінюється кнопкою «Новий PIN».
- **Колеги:** «Налаштування» → «Додати колегу-вчителя». Усі вчителі бачать усі класи.
- **Уроки:** учень бачить урок лише свого класу й лише з дня уроку.

## Локально

```bash
uv venv && uv pip install -r requirements-dev.txt
```

```bash
.venv/bin/python dev.py
```

`dev.py` піднімає вбудований Postgres у `.pgdata/`, код першого запуску — `dev`. Сайт: http://localhost:8000

```bash
.venv/bin/python -m pytest
```

Тест `tests/test_app.py` перевіряє права доступу: учень не бачить чужих відповідей, оцінок і файлів, не бачить уроків інших класів і майбутніх уроків.

## Обмеження

- Ліміт спроб входу (5 помилок → 15 хвилин) зберігається в пам'яті одного процесу.
- Вчитель отримує всі дані школи одним запитом; на великих обсягах відповіді треба буде розбити на сторінки.
- Змін схеми на живих даних ще не було — коли знадобляться, потрібен інструмент міграцій.
